# 📚 ASP.NET Core MVC Tutorial Series - Book Management System

Welcome to the **ASP.NET Core MVC Tutorial Series!**

In this series, we'll build a complete **Book Management System** step by step using ASP.NET Core MVC, C#, Entity Framework Core, and SQL Server.

This repository contains the source code developed throughout the tutorial series. Each lesson introduces a new concept and adds another feature to our application.

Whether you're new to ASP.NET Core MVC or looking to strengthen your understanding of it, this project will help you learn the fundamentals through practical, hands-on development.

---

## 🚀 What You'll Build

By the end of this series, you'll have a Book Management System where users can:

- View a list of books.
- Create new books.
- Edit existing books.
- Delete books.
- Search for books by title or author.
- Filter books by author.
- Navigate through paginated results.
- Register and log in to the application.
- Log out securely.

We'll also improve the user interface with Bootstrap and add proper form validation.

---

## 🛠️ Technologies & Tools

The project uses the following technologies:

- **C#** - Main programming language
- **ASP.NET Core MVC** - Web application framework
- **Entity Framework Core** - Object-relational mapper (ORM)
- **SQL Server** - Database management system
- **Bootstrap** - Responsive UI framework
- **ASP.NET Core Identity** - User authentication and identity management
- **Razor Views** - Dynamic HTML rendering
- **Data Annotations** - Model and form validation
- **Visual Studio** - Development environment

## 📖 Tutorial Roadmap

The tutorial series is divided into 11 lessons, starting with the fundamentals and gradually moving toward more advanced ASP.NET Core MVC concepts.

| # | Topic | What You'll Learn |
|---|---|---|
| 01 | Introduction to ASP.NET Core MVC | MVC architecture, project structure, and how MVC works |
| 02 | Controllers, Actions & Routing | Creating controllers, action methods, and understanding routing |
| 03 | Views, Layouts & ViewData | Layouts, ViewData, ViewBag, and Partial Views |
| 04 | Models, ViewModels & Model Binding | Creating models and ViewModels, and understanding model binding |
| 05 | Entity Framework Core & CRUD | Connecting to SQL Server and implementing Create, Read, Update, and Delete operations |
| 06 | Improving UI with Bootstrap | Building responsive layouts, tables, forms, and alerts |
| 07 | Form Validation | Data Annotations, ModelState, client-side and server-side validation |
| 08 | Search, Filtering & Pagination | Searching books, filtering by author, and implementing pagination |
| 09 | Authentication with ASP.NET Core Identity | Configuring Identity, user registration, login, and logout |
| 10 | Authorization & Role-Based Access Control | Protecting pages and actions, managing roles, and controlling user access |
| 11 | Deployment & Production Configuration | Preparing the application for production and deploying it |

### Book Management
- Add new books.
